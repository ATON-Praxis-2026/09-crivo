Chaves do Autopilot

Boa notícia: só existe uma chave para configurar — a da Anthropic, que ativa o Claude com busca web. A consulta de CNPJ usa a BrasilAPI, que é gratuita e sem chave (nada a fazer). Siga os passos na ordem: cada um diz onde clicar e como saber que deu certo.

  1. 1

    Criar a chave no console da Anthropic

    • Acesse console.anthropic.com e entre — ou crie uma conta, se ainda não tiver. Se o endereço virar platform.claude.com, está tudo certo: é o mesmo console, que mudou de endereço.
    • No menu lateral, siga este caminho (ou vá direto para console.anthropic.com/settings/keys):
    Settings→ API Keys→ Create Key
    • Dê um nome para a chave — por exemplo, autopilot-aton.
    • Copie a chave (começa com sk-ant-). Ela aparece uma única vez: guarde em um local seguro, como um gerenciador de senhas.
    • Ainda no console, confira se a conta tem créditos em Settings → Billing — a API é pré-paga; sem crédito, a chave não funciona.

    ✓Deu certo quando: a chave aparece na lista de API Keys com o nome que você deu — e a cópia está guardada com você.

  2. 2

    Cadastrar no app local (arquivo .env)

    • Abra o PowerShell na pasta autopilot do projeto (no Explorador de Arquivos, entre na pasta, digite powershell na barra de endereço e aperte Enter) e copie o modelo de configuração:
    Copy-Item .env.example .env
    • Abra o arquivo .env em qualquer editor (o Bloco de Notas serve) e cole a sua chave logo depois do sinal de igual:
    ANTHROPIC_API_KEY=sk-ant-…cole-a-sua-chave-aqui…
    • Salve o arquivo. As outras linhas do .env (DATA_STORE, NEXT_PUBLIC_DEFAULT_CITY, MODEL_…) são opcionais — pode deixar como estão.
    • Reinicie o servidor: no terminal onde o app roda, aperte Ctrl+C e rode de novo:
    npm run dev

    ✓Deu certo quando: o servidor sobe sem erro e o terminal mostra http://localhost:3000.

  3. 3

    Conferir que a pipeline real ativou

    • Abra http://localhost:3000 no navegador.
    • Repare no topo da tela: o banner de modo demonstração deve ter sumido. Não há mais nenhum ajuste a fazer — com a chave no lugar, a pipeline real (Claude + BrasilAPI) ativa sozinha.

    ✓Deu certo quando: o banner de demonstração não aparece mais e uma pesquisa nova traz fornecedores reais, com evidências clicáveis.

  4. Atenção ao custo

    Cada ranking real de 10 fornecedores custa cerca de US$ 1,50 a US$ 2,50 — são ~70 a 90 buscas na web por rodada. O app já limita as buscas por agente (8 no Descobridor, 6 no Verificador, 4 no Refinador), mas rode o modo real com intenção: para treinar apresentação, use o passo 4 e não gaste nada.

  5. E a chave da Receita Federal?

    Não existe — e isso é de propósito. A consulta de CNPJ (situação cadastral, data de abertura, CNAE, porte) sai da BrasilAPI, um serviço público e gratuito que não pede chave, cadastro nem configuração. O app já chama brasilapi.com.br/api/cnpj/v1/… sozinho, com espera e retentativa automáticas. Ou seja: com a chave da Anthropic do passo 1 no lugar, o sistema inteiro está completo — não procure uma segunda chave, ela não existe.

  6. 4

    Ensaiar sem gastar (MOCK_MODE)

    • Quer treinar o pitch sem consumir créditos? No .env, acrescente (ou descomente, tirando o #) esta linha:
    MOCK_MODE=true
    • Salve o arquivo e reinicie o servidor (Ctrl+C e npm run dev). A linha força o modo demonstração mesmo com a chave cadastrada — o app roda a mesma jornada com dados simulados, de graça.
    • Para voltar ao modo real: apague a linha (ou devolva o # na frente), salve e reinicie o servidor de novo.

    ✓Deu certo quando: o banner de demonstração volta a aparecer — sinal de que nenhuma busca paga está sendo feita.

  7. 5

    Ativar na Vercel opcional

    • A demo pública autopilot-eventos-demo.vercel.app roda em modo demonstração de propósito. Se um dia o time quiser o modo real também lá:
    Painel da Vercel→ projeto autopilot-eventos-demo→ Settings→ Environment Variables
    • Adicione a variável ANTHROPIC_API_KEY, cole o valor da chave e salve.
    • Depois clique em Redeploy para a mudança valer.
    • Limitação atual: o modo real só é suportado oficialmente no computador local. Na Vercel o app guarda o andamento da pesquisa em memória (sem banco), e uma pesquisa real pode se perder no meio do caminho — a troca por banco de produção está no roadmap (veja o README).
    • Recomendação do time: manter a demo pública em modo demonstração (qualquer pessoa pode acessá-la e gerar custo) e usar o modo real só localmente, na hora do pitch.

    ✓Deu certo quando: após o redeploy, o banner de demonstração some no endereço público — mas, se uma pesquisa real travar lá, é a limitação de memória acima, não a sua chave.

  8. Segurança da chave

    • O .env nunca vai para o git — ele já está no .gitignore do projeto. Não mude isso.
    • Não cole a chave em chats, prints, slides ou documentos compartilhados.
    • Se ela vazar: revogue no console da Anthropic (Settings → API Keys), crie outra e atualize o .env.

Se algo der errado

Apareceu "erro 401" ou "authentication error"

A chave está errada, incompleta ou foi revogada. Volte ao console da Anthropic, crie uma chave nova (passo 1), cole de novo no .env (passo 2) e reinicie o servidor.

Erro falando de créditos ou billing

A conta está sem saldo — a API é pré-paga. No console da Anthropic, abra Settings → Billing e adicione créditos. A mesma chave volta a funcionar em seguida.

O banner de demonstração não some

O app só lê o .env quando o servidor sobe. Pare com Ctrl+C e rode npm run dev de novo. Se ainda assim não sumir, confira se a linha MOCK_MODE=true não ficou ativa no .env — ela força o modo demonstração de propósito.

Consulta de CNPJ falhou (BrasilAPI)

A BrasilAPI é um serviço público e às vezes oscila. Tente de novo: o app já espera e retenta sozinho (backoff automático). Não há chave nem configuração a ajustar aqui.
